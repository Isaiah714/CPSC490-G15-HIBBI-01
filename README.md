## Project summary

 The project aims to develop a lightweight, ECS based game engine framework. Our approach is to develop a lightweight, extensible game development framework centered around the Entity Component System (ECS) architecture, with emphasis on efficient resource usage and cross platform support (including Windows, Linux, and potentially Mac). A small game prototype, a top down 3D "bullet heaven" roguelite, with high entity counts to demonstrate the ECS architecture, as well as the engine's core player interaction, enemy behavior, and gameplay loop functionality. The prototype will demonstrate the foundations of the core engine architecture, basic real time rendering functionality, player input, core gameplay functionality, and a basic editor functionality which we can expand on during the full project implementation.
